# D-136 · A Civ prompt can show 120 events: civ-p1.1 and civ-p2.1

- **Date:** 2026-11-12
- **Decision:** A prompt shows the latest 40 events of a player; the older ones are only counted ("N earlier events are not shown"). In Throne of Tokens that is too few: talk and a nation's results reach a model only through these events (D-130), and with six nations that all talk (3 messages and 3 offers each) plus their own results, one nation gets up to 45 new events in a turn (measured in a 20-round match of scripted talkers; random bots give at most 16). So the oldest events of the turn are cut. `GamePlugin.history_limit(settings)` (default 40, so every other game's prompt is byte for byte what it was) is read by the agent runner and the cost estimate. Civ answers 120 for the new prompt versions `civ-p1.1` and `civ-p2.1`, which read exactly the text of `civ-p1` and `civ-p2` and differ only in this limit (the D-121 pattern). `civ-p1` and `civ-p2` stay as they are.
- **Why:** nothing of the turn a model answers should be dropped, and an experiment that ran on `civ-p1` must stay comparable; so the fix is a version, not an edit. 120 is the 45 of a talkative turn plus a couple of earlier rounds; a prompt of 120 short event lines is about 3,000 tokens, which the free estimate for a Civ match prices.
- **Alternatives:** raising `HISTORY_LIMIT` for everyone (changes every game's prompt and goldens); a per-round summary of old events (the model should read what was said, not a summary); cutting what other nations may send (a rule change).
