# D-119 · Werewolf p4 whole-match strategy text; Liar's Deck p1 stays frozen with a known defect

- **Date:** 2026-11-12
- **Decision:** (1) `werewolf-p4` is a new prompt version: `rules_v4.md` is `rules_v3.md` plus a neutral "Think about the whole match" section (win for the team, lying and hiding are allowed, compare the legal options by what others do next, keep facts apart from claims, one plan for tomorrow, a short thought), and its summary is the p3 summary plus the living players the move can name. It has no quota, no model-specific wording, and no count computed from the full state. `werewolf-p1` to `p3` are untouched. (2) `liars_deck-p1` stays byte for byte as the E1 league ran it. **Known issue:** its `rules.md` says private thoughts are "the plain text of your answer", while the shared system prompt says to put the thought inside the tool call and write nothing outside it. The fix goes only into a new Liar's Deck version (`liars_deck-p3`). (3) `civ-p2` carries strategy text only and `private_plan` is an independent setting (a 2 x 2), agreed with the Researcher.
- **Why:** the E1 baselines must stay comparable; a prompt change must be a recorded version that can be A/B-tested. The audit of match be2f808a (research-runs/latest-match-audit) found the contradiction. No causal claim is made for p4: it is a hypothesis for a paired test in an approved stage.
- **Alternatives:** editing p1 in place (breaks the E1 baselines); copying p2's "play honestly, bluff rarely" advice (it narrows play and acts like a quota); folding the private plan into a prompt version (cannot tell which part helped).
